# 🧑‍💼 Employee Management System

> A Java-based desktop application designed to efficiently manage employee records including personal details, salary, and attendance.

---

## 📌 Overview

The Employee Management System is developed using **Java (Swing)** and **MySQL**.  
It allows organizations to manage employee information in a structured and organized way.

This project demonstrates practical knowledge of:

- Object-Oriented Programming (OOP)
- CRUD Operations
- JDBC (Java Database Connectivity)
- GUI Development using Swing
- Database Integration

---

## 🚀 Key Features

- ➕ Add New Employee  
- 📝 Update Employee Information  
- ❌ Delete Employee Records  
- 📋 View Employee List  
- 💰 Salary Management  
- 📊 Structured Data Handling  

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|----------|
| Java | Core Programming |
| Swing / AWT | GUI Design |
| MySQL | Database |
